# TRUSTTRACE Machine Learning Forensics Pipeline

The TRUSTTRACE Machine Learning Pipeline provides deep-learning assisted visual artifact detection and classification for digital evidence verification.

## Core Principle: Evidence Fusion Independence

**CRITICAL FORENSIC RULE**: The machine learning prediction is treated as an advisory forensic signal and **never** automatically becomes the final TRUSTTRACE verdict. The final forensic assessment is governed strictly by the deterministic **Evidence Fusion Layer** (`backend/forensic/fusion.py`), which synthesizes file metadata, quantization tables, noise residuals, ELA anomalies, structural screenshot checks, and optical text analysis alongside model inferences.

---

## Supported Forensic Classes

The model classifies digital evidence into four primary technical classes:
1. `REAL` - Authentic, unmanipulated photographic or captured image.
2. `EDITED` - Digitally altered image (splicing, clone-stamp, localized modifications, retouching).
3. `AI-GENERATED` - Synthetic imagery generated by diffusion models, GANs, or neural autoregressive generators.
4. `SCREENSHOT-MANIPULATED` - Digital capture/screengrab containing forged, spliced, or altered text/UI components.

### Handling `UNKNOWN` via Uncertainty & Out-of-Distribution (OOD) Logic

`UNKNOWN` is **not** treated as a simplistic visual class with random training samples. Real-world forensic evidence frequently falls outside known distribution bounds or exhibits severe visual ambiguity. 

The pipeline handles `UNKNOWN` systematically using:
- **Maximum Softmax Probability (MSP)**: Low confidence below threshold $\tau_{\text{conf}}$ (default: 0.55).
- **Normalized Shannon Entropy**: Prediction distribution entropy $H = -\sum_{i=1}^K p_i \log_K p_i$. High entropy ($H > \tau_{\text{entropy}}$, default: 0.82) signals high uncertainty.
- **Energy-Based Out-of-Distribution Score**: Free energy score $E(x; T) = -T \cdot \log \sum_i \exp(z_i / T)$. Scores exceeding the OOD threshold flag out-of-distribution inputs.
- **Temperature-Calibrated Probabilities**: Softmax logits scaled via validation-derived temperature parameter $T$.

When uncertainty exceeds thresholds, the inference engine returns:
```json
{
  "model_version": "trusttrace-v1.0.0",
  "prediction": "UNKNOWN",
  "probabilities": {
    "REAL": 0.28,
    "EDITED": 0.24,
    "AI-GENERATED": 0.26,
    "SCREENSHOT-MANIPULATED": 0.22
  },
  "uncertainty": 0.985,
  "status": "completed"
}
```

## Reproducibility & Pipeline Workflow

### 1. Training (`train.py`)
```bash
python train.py --config config/dataset_config.json --epochs 20 --batch-size 32 --lr 1e-4
```
Outputs model checkpoint to `model/checkpoints/` and detailed metadata to `model/metadata/`, computing the strict SHA-256 checksum upon finalization.

### 2. Post-Hoc Calibration (`calibrate.py`)
```bash
python calibrate.py --model-path model/checkpoints/trusttrace_best.pt --val-dir data/val
```
Finds optimal temperature parameter $T$ minimizing negative log-likelihood on uncorrupted validation data.

### 3. Comprehensive Evaluation (`evaluate.py`)
```bash
python evaluate.py --model-path model/checkpoints/trusttrace_best.pt --test-dir data/test --ood-dir data/ood
```
Computes and records:
- Multi-class Accuracy, Precision, Recall, Macro-F1
- Per-class confusion matrix
- Expected Calibration Error (ECE) and Maximum Calibration Error (MCE)
- OOD AUROC and False Positive Rate at 95% TPR (FPR95)

### 4. Direct Inference API (`predict.py`)
```bash
python predict.py --image path/to/evidence.jpg --model-path model/checkpoints/trusttrace_best.pt
```
Returns structured JSON adhering to the TRUSTTRACE specification.
